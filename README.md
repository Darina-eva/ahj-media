# Timeline

Лента постов с текстовыми записями и координатами. При отправке текста (Enter) запрашиваются координаты через Geolocation API. Если они недоступны, открывается модальное окно для ручного ввода широты и долготы. Функция `parseCoords` разбирает ввод в форматах `51.50851, -0.12572`, `51.50851,-0.12572` и `[51.50851, -0.12572]`, а при неверном формате выбрасывает исключение, которое подсвечивает поле как невалидное. Для функции написаны авто-тесты (Jest). Все данные хранятся в памяти.
